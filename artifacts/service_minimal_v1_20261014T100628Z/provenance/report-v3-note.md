# report_v3 来源说明

report_v3 是最终入口来源绑定修复后生成的报告，消费既有冻结 data/run/evaluation/admission；没有 prepare、fit、重评分或重评价。研究结论保持不变。

report 和 report_v2 的原始字节保留；后续引用入口来源校验及当前执行代码 provenance 时使用 report_v3。既有模型、评价与 admission 不因此失效。

本目录 t0-guard-report.md、t4-evaluation-report.md 从临时 SDD workspace 原样迁入；其中 task brief、review 等名称是当时的本地协作材料引用，不表示它们已归档为永久研究资产。
