# 当前窗口 BERT 语义评分实验

本实验将冻结 BERT 向量从“过去窗口上下文”改为“当前窗口语义异常评分”。它使用每个服务 Normal fit 窗口的 BERT 向量均值作为参考，当前窗口采用 cosine distance；融合分支再将语义距离与原服务先验 GRU 分数分别按 Normal calibration 的 robust scale 标准化后相加。两种模式均使用独立配置和新输出目录，未覆盖原模型。

三 seed 主评价结果：

|路线|AUROC|AP|
|---|---:|---:|
|原服务先验 GRU|0.823970|0.680061|
|当前窗 BERT 语义-only|0.632881|0.175363|
|当前窗语义 + GRU 融合|0.671317|0.413700|

六组运行均通过递归 `check_run`，主集均为3297窗，产物各6项，使用 selected17、Normal-only参考、独立校准和原主评价划分。当前窗口语义距离及融合均明显低于原 GRU，因此停止继续深挖该分支。该结果不证明冻结 BERT 或日志语义在其他目标、训练方式或数据版本中必然无效；它只说明当前“服务内 Normal 均值 cosine distance + 固定 robust-z 融合”没有提供有效增量。

后续改进转回原始服务先验 GRU，重点审阅 MLflow 训练过程、误差分量、上下文长度、残差/评分头及 Normal-only 可选目标；不再继续 POOL/DNS 或当前语义分支搜索。
